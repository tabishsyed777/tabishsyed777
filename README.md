## Selected projects

### [Pathfinder — AI Website Testing Agent](https://github.com/tabishsyed777/AI-website-testing-agent)
A product concept for an AI agent that explores website user journeys and turns findings into reproducible reports. The live site is an interactive prototype; its sample run does not scan a live website.

[View the prototype](https://tabishsyed777.github.io/AI-website-testing-agent/)

### [RescueGrid](https://github.com/tabishsyed777/rescuegrid)
An interactive simulator for comparing quickest and risk-aware supply routes across a fictional emergency map. It is an educational demo, not a real emergency response tool.

### [DiaCare AI](https://github.com/tabishsyed777/DiaCare-AI)
A patient-portal prototype for reviewing health records with clear privacy boundaries. Use synthetic demo data only; it is not a clinical system.
