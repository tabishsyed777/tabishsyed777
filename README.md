## About me

<img align="right" alt="Animated developer working at a TABZ-branded laptop" width="300" src="https://raw.githubusercontent.com/tabishsyed777/tabishsyed777/main/assets/tabz-coding.gif" />

I build projects to understand how modern technology becomes useful software. My current work explores applied machine learning, reinforcement-learning environments, data systems, cloud-aware automation, agent evaluation, and local-first security tools.

I use AI tools for ideation, coding, debugging, testing, documentation, and GitHub automation. I am transparent about that workflow: I define the problem, review the implementation, run the checks, understand the design, and document the limitations of each project.

| 🎯 Focus | 🌱 Growth mindset |

## Featured work

| Project | What it demonstrates |
|---|---|
| [TrajectoryForge](https://github.com/tabishsyed777/TrajectoryForge) | Turns synthetic agent failures into inspectable task contracts, reward specifications, and replay evidence. |
| [TaskFoundry](https://github.com/tabishsyed777/Tabz-task-foundry-) | Compiles Python data-pipeline repair tasks with held-out cases, Docker grading, and Harbor export. |
